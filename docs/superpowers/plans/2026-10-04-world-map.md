# World map of countries — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "Список / Карта" switch on the Countries screen; the map view fills each country by visited percentage in four levels, tapping a country opens its existing screen.

**Architecture:** Bundled Natural Earth 1:50m polygons (`src/assets/world.json`, props `{ code }`) plus one point per country (`world-points.json`) for small countries. A pure module maps `CountryStat[]` to a MapLibre `match` expression. `WorldMapView` renders an empty-style `Map` with a `GeoJSONSource` + fill/line layers and a circle layer for small countries; `CountriesScreen` hosts the switch.

**Tech Stack:** React Native 0.83, Expo 55, `@maplibre/maplibre-react-native` ^11.3.10 (`Map`, `Camera`, `GeoJSONSource`, `Layer`), Jest + Testing Library, `mapshaper` run through `npx` in the build script only (not added to package.json).

**Spec:** `docs/superpowers/specs/2026-10-04-world-map-design.md`

## Global Constraints

- Natural Earth 1:50m `admin_0_countries`, simplified, target 1–2 MB for `world.json`; ISO code from `ISO_A2_EH` (not `ISO_A2`, which is `-99` for France and Norway).
- Four levels: `percent == 0` neutral grey; `< 1` light green; `1–10` medium green; `> 10` deep green. `percent` is already in percent (0–100), see `buildCountryList`.
- Tap on a country calls the same `onOpenCountry(CountryStat)` as a list row; codes without a `CountryStat` are not tappable.
- Fog palette is not touched. Light and dark themes get their own level colours.
- Works offline: empty style, no basemap, no network.
- The border file is loaded lazily with `require` inside the map view, never at app start.
- Strings exist in both `src/i18n/ru.ts` and `src/i18n/en.ts` (`dictionaries.test.ts` enforces parity).
- Camera: whole world, zoom clamped, rotation and pitch off.
- Run Jest as `npx jest --testPathIgnorePatterns .worktrees` (the old worktree copy fails to load native modules).

## Review Focus

- A code in the GeoJSON that is not in `COUNTRIES` (disputed territory): must stay grey and not crash the tap handler. Pinned in Task 1 and Task 3.
- `percent` that is `NaN`, negative or `Infinity`: must render as level 0, not throw. Task 1.
- A country visited by a hair (`percent = 1e-9`): must get the light-green level, not grey. Task 1.
- Border file fails to load (`require` throws): the view shows the list's failure message instead of a blank screen. Task 3.
- Switching to the map while `pending` is true, then stats arrive: colours update without remounting the map. Task 3.
- Switching Список → Карта → Список keeps the list scroll and does not tear down the native map twice. Task 4.

### Task 1: Level and colour logic

**Files:**
- Create: `src/lib/geo/worldMapColors.ts`
- Test: `src/lib/geo/worldMapColors.test.ts`

**Interfaces:**
- Produces:
  - `type Level = 0 | 1 | 2 | 3`
  - `levelFor(percent: number): Level` — non-finite or `<= 0` → 0; `< 1` → 1; `<= 10` → 2; else 3.
  - `levelColors(scheme: ColorScheme): Record<Level, string>` — hex colours, level 0 grey, 1–3 green shades, separate sets for light and dark.
  - `fillColorExpression(countries: CountryStat[], scheme: ColorScheme): ExpressionSpecification` — `['match', ['get', 'code'], ...pairs, levelColors[0]]`, pairs only for countries with level > 0 grouped by level (one array of codes per level).
  - `waterColor(scheme: ColorScheme): string`
  - `SMALL_COUNTRY_KM2 = 3000`
